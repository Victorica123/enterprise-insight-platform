# 产品知识

## 一句话定位

Enterprise Insight Platform 将客户访谈、需求评审、故障复盘等视频及配套业务文档，转化为可回放验证的需求证据、结构化洞察、可评审 PRD 和可追踪行动项。

它不是“视频站 + 聊天机器人”的拼接，也不是通用网盘。核心价值是缩短从非结构化沟通到可信业务决策的距离。

## 目标用户

- 产品经理：从多场访谈中提取需求、冲突、优先级和 PRD 草案。
- 研发与测试负责人：查看每条需求的原始证据、约束和验收口径。
- 项目或交付负责人：跟踪风险、待确认问题、负责人和截止时间。
- 企业管理员：管理租户、成员、数据边界和审计记录。

## 核心业务闭环

1. 用户上传会议视频并查看可靠的媒体处理进度。
2. Media Service 生成带时间段和说话人的转写片段。
3. 转写完成事件被 Agent Service 幂等接收，片段成为可检索证据。
4. 用户在统一工作台跨视频提问，答案引用可点击回放的时间段。
5. Agent 按意图、干系人、领域深挖、风险、收敛、PRD 六阶段产出需求分析。
6. 未收敛信息进入人工补充或确认；会话冻结 objective 排序后的授权证据，等待后从阶段检查点恢复。
7. PRD 发布进入人工审批：个人 Workspace 由 OWNER 二次明确确认，团队 Workspace 由不同成员四眼审批，结果保留审计链。
8. 发布事务固化不可变 PRD 版本，并生成仍需人工决定的知识候选与行动项草稿。
9. 知识候选独立批准后，以原始证据、PRD 版本和内容哈希物化为受治理知识，并进入后续授权 RAG。
10. 已批准知识可经独立申请与审批形成替代版本或撤回；历史版本不删除，未来检索只使用活跃版本，历史问答回放显示引用的当前失效状态。
10. 行动项只能进入受控工单审批；坏案例进入评测和规则改进流程。

## 首条可交付纵向链路

首条纵向链路已经贯通：统一登录与租户边界 → 个人/团队 Workspace 创建、邀请与显式切换 → 视频转写进入 Agent → 团队证据共享与个人隔离 → 时间戳证据问答 → 六阶段等待/恢复 → 证据化 PRD → Workspace 策略审批与审计 → 不可变版本 → 知识候选人工决定 → 行动项工单审批。旧图谱、工单与明细审计也已完成 tenant/owner 迁移，不再以 JWT 模式 503 代替授权。

团队 Workspace 的邀请、角色、共享范围和活跃 Workspace 切换语义已经由 ADR-0006 固化并实现。ADR-0014 已批准生产试点的 Keycloak OIDC、RS256/JWKS、MySQL、保留期限、外部模型 tenant 白名单和 99.5% SLO；近实时撤权、公开发布迁移与灾备仍需目标环境验证。

注册用户自动获得一个个人工作区并成为 OWNER；OWNER 可创建团队空间，OWNER/ADMIN 可签发一次性短期邀请码，已注册用户接受后以 MEMBER 加入。用户必须显式切换 active Workspace，服务端才根据成员关系重签 JWT。个人资源按 owner 私有，团队资源按 tenant 共享读取，`owner_id` 始终保留创建者与审计归属。

## 成功标准

- 同一身份可在一个前端完成上传、进度查看、提问和证据回放。
- 任一跨租户或跨 owner 访问被服务端拒绝，而不是只在 UI 隐藏。
- 转写完成重复通知不会产生重复片段或重复索引。
- 视频答案的关键结论包含 `asset_id`、开始/结束时间和可回放定位。
- 模型不可用时，媒体处理事实、已入库证据和审批状态仍可查询。
- PRD 中无法由证据支持的内容被标识为假设或待确认，而非伪装成事实。
- 个人发布需要两次显式操作；团队提交者不能批准自己的 PRD，跨租户审批表现为资源不存在。
- 同团队成员可以共同查看视频、文档、分析、知识、图谱与工单；个人空间仍不可借同一账号或 tenant 绕过 owner 隔离。
- VIEWER 只读；MEMBER、ADMIN、OWNER 可写；角色切换只能由 Media Service 根据服务端成员关系重新签发受信令牌。
- 发布成功必须同时生成可校验哈希的不可变 PRD 版本；知识与行动执行都保留独立人工门禁。批准知识必须能够被未来问答召回并反查 candidate、PRD version、知识版本、内容哈希和原始证据；替代/撤回后旧版本仍可审计但不能进入未来回答。
- 上述核心闭环可在本机完成验收，不依赖公网服务器、正式域名、云存储或外部模型账号。
- 同一恢复 token 的并发确认只有一个成功；恢复前后证据 hash/revision 与阶段 1–4 保持一致，避免等待期间材料变化造成结论漂移。

## 当前非目标

- 取代专业视频剪辑、直播或内容分发平台。
- 允许 Agent 无审批地向外部系统执行高风险写操作。
- 在首个整合版本中同时支持任意身份供应商、任意消息队列和任意模型平台。
