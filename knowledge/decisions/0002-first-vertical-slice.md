# ADR-0002：首条整合纵向链路

- 状态：已接受
- 日期：2026-08-29

## 背景

整合可以从页面拼接、完整 PRD Agent 或基础设施统一开始。为了尽快验证产品价值，需要一条同时触达身份、媒体、Agent 和证据的用户路径。

## 决策

首条链路按以下顺序交付：

1. 两个后端统一 JWT、tenant 与 owner 语义。
2. Media Service 产生带时间段的转写事件，Agent Service 幂等摄取。
3. Agent 问答返回可验证、可回放的时间戳证据。
4. 在同一租户与授权范围内支持跨视频问答。
5. 一个 React 工作台串联上传、进度、提问与回放。

六阶段需求分析、PRD、审批和行动项在此链路稳定后扩展。

## 结果

该顺序会较早暴露身份和契约问题，并以可见业务价值验证整合。它不会为了短期演示绕过真实授权或使用无时间戳的伪视频引用。
