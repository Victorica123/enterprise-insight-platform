# ADR-0016：有界主题记忆与共用问答流水线的 SSE

- 状态：已接受并实现
- 日期：2026-09-13
- 范围：架构优化计划阶段 0.6、1.7 与阶段 2；延续 ADR-0006 的 Workspace 语义

## 决策

`/chat` 与 `/chat/stream` 经 `architecture.conversation` 进入同一个 `chat_service`，共用授权、记忆、执行计划、检索、引用审核、治理与计量。旧客户端省略 `memory_mode` 时仍为 `none`；提供会话 ID 时仍必须通过 JWT scope 校验。个人会话按 tenant + owner 私有，团队会话按 tenant 共享，逐轮保留实际 actor 归属。

记忆只从已授权用户问题中提供主题提示，不把旧回答或旧引用作为新证据。`window` 取最近四轮、最多 2200 字符；`summary` 另保留最多 1400 字符的摘要，每次推进最多六个旧轮次。模型摘要必须符合结构、长度和已有客户/项目标识约束，失败退回规则；受限的字面标识补全负责指代改写，不宣称任意对话理解。比较多个主题后的“它”不得默认为最后一个主题。每轮重新授权并检索活跃证据。

相对置信度用于已授权客户/项目候选，不套用在可同时成立的“原因/风险”等意图上。明确主题和主动跨主题比较不被误拦；无候选保留原证据不足路径。相关性过滤与相邻块合并都排除明确不同主题的块；合并限定同文档、同章节、相邻块和证据字符预算，视频不合并，时间定位保持独立。

会话表保存 revision、租约及预算预留。每次请求仍受默认模型 8 / 工具 6 上限约束，会话累计上限为 40 / 30；先预留、完成或可处理取消后退还未使用额度。崩溃留下的预留保守计入消耗。默认 120 秒租约每三分之一周期续租；过期不得续活，旧执行者无法提交或清除新租约，阶段与调用入口检查失去租约的状态。JSON 冲突为 409；SSE 开始前的授权/领取冲突使用 HTTP 状态，开始后的失败使用脱敏 `error` 事件。

SSE 发送 `plan/stage/delta/sources/follow_up/done/error`，信封含 conversation/exchange ID 与时间。答案通道使用 `AsyncOpenAI` 真流式，队列最多 64 项、空闲 15 秒发送心跳；本地模板在计算完成后分片。`delta` 是待核验文本，只有 `done` 是引用审核后的最终 `ChatResponse`。停止或断连取消上游流、退还可确定的未用预算，不保存未完成回答；在取消被服务端观察前已经完成的轮次可以保留。阻塞规划调用不能强制中断，仍受超时与重试上限约束。

Web 用 `fetch/ReadableStream`，通过 generation 与 AbortController 阻止停止、新建、登出或 Workspace 切换后的迟到响应回写。会话数据沿用既有审计保留期（默认 365 天），清理跳过活跃租约；不新增独立保留政策。

## 取舍与验证

保留成熟同步执行器，通过事件 sink 连接异步传输，不把全部业务函数改写为生成器。规则记忆范围有限，但主题提示不能绕过证据、权限或审批。没有引入 Redis、自治 Agent 或新模型选择。

回归覆盖两种传输、旧客户端、隔离、竞争领取、续租、失效执行者、取消退预算、流首字、provider 关闭和主题串入；Conversation V1 另覆盖九个确定性业务场景。真实外部模型质量与生产并发需独立验收，最新结果见 [QUALITY.md](../QUALITY.md)。
